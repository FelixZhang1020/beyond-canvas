# 老师评价

创作活动顺序为「老师评价 → 聊聊你的画 → 让画动起来／形体与光影 → 做本故事书」。
老师评价根据当前画作生成完整的教师点评；现有聊天入口仍用于孩子的故事对话。
切换到老师评价后点击生成，不自动产生费用。重复生成保留作品集里的历史结果。

## 点评方式

方法源于[《点评集合》的图文提炼](../../skills/art-feedback/references/teacher-commentary.md)：
以具体观察支撑判断，解释画面处理与视觉效果，按作品选择色彩、空间、笔触、
肌理、动作叙事等重点。正文采用三个自然段，中文目标约 300–500 字，包含总体
特点、具体分析、值得保留的处理及最多一条有依据的小提升。不强凑缺点。
素描可谈结构、明暗与虚实；彩画尊重夸张、非写实色彩和混合视点。
不以提问结尾，不给儿童、作品打分，不宣称模型输出已经获得教师认证。

**长度门槛更正。** 原格式检查按字符长度放行 180–5000，中英文共用一套
界限；英文另按拉丁字母数判断，100 个字母（约二十词）即可通过，所以一段两句话的
回复能被当成完整教师评价保存。现在按语言各自计量：中文数汉字，英文数单词，界限
取上述目标范围上下各放宽两成（中文 240–600 字，英文 144–336 词）。上限高于文中
写的 500，是因为真实验收的两份评价为 535 与 578 字，见下文。界限写在
`studio/conversation/teacher_review.py` 的 `TARGET`，由 `tests/conversation/test_teacher_review.py` 校验。

与原有聊天入口不同，本模块可以提出有依据的温和建议。它不套用聊天的短句、
开放问题和「彩画不纠错」规则，也不把老师评价加入孩子的对话上下文或朗读队列。
不会推断作者身份、学习经历、用时、心理或未提供的材料／技法信息。

提示词的唯一运行来源是 [teacher-review.txt](../../studio/prompts/teacher-review.txt)。
运行时不发送参考文档、学生称呼或其他参考配图；只发送当前原图及课程说明，
参考中的分析方法已经写入提示词。

## 生成与保存

`teacher-review` 使用原有单图请求、筛查、取消、计量和保存流程。
固定使用 StepFun `step-3.7-flash`（复用 stepfun profile 的 director 配置），
不会随聊天入口的本地模型切换而降级。缺少服务配置时明确失败。

通过图片筛查后，依次生成初稿、独立看图复核、结合复核意见定稿，三次均携带
当前原图。复核结果检查结构；定稿检查基本篇幅、指定语言及无问题句，沿用
原有图片文字脱敏。复核是模型辅助，不能保证所有视觉判断都正确，也不输出
自评高分。错误结果不以成功评价发布，取消后不再发起下一次模型调用。

评价与当前画作关联并存入作品集。重开课程恢复最后一次成功评价，失败或取消
不会覆盖旧评价；「回顾」下有独立的「老师评价」入口。

## 验证

新增测试覆盖三次原图调用、计量与保存、聊天隔离、图片拒绝、问题句拒绝、
复核格式错误、调用间取消，以及前端课程恢复、清理和独立回顾显示。
本机开发验收服务为 http://127.0.0.1:7070/，使用独立测试作品集
`.studio/teacher-review-dev/portfolio.sqlite3`；首次验收未改变原 7060 课堂进程。

最终验证：963 项非 live 后端测试通过（8 项 live 未运行），223 项
前端测试通过，页面构建与结构检查通过。浏览器已完成样例库上传、真实生成、
课程重开恢复、聊天隔离与独立回顾；390px 宽度下文档无横向溢出。

真实模型验收为样例库的一幅冬日雪山木屋画。最初两阶段输出 578 字，存在
材料／湿画法推断和依据不足的建议；加入独立复核及更明确的边界后，最终三阶段
输出 535 字，完整保存为请求 `85fb9590f8e3`。两版均保留在本机测试作品集中，
最终输出见 `.studio/teacher-review-dev/85fb9590f8e3.json`。该结果仍有较密集的术语，
一次样例不足以证明所有画作稳定达到高质量；本轮没有重跑全部 74 张样例。

## 课堂服务接入修复

用户在实际使用的 `http://localhost:7060/` 看到了新页面，但服务进程尚未载入
`teacher-review`，提交因此被拒绝。只更新 7070 预览不能完成原课堂功能接入。
已返回作品集、保留课程后，以原 `local-first` 参数优雅重启 7060；健康检查确认
新任务已注册，原 VoxCPM2 语音配置保留。原课程 8 幅画恢复，第 8 幅原失败任务
重新提交后已被服务接受。随后端到端实测又发现复核回复直接 `json.loads` 时
抛出 `JSONDecodeError`，导致中断。已复用既有 `judge_json` 处理格式包裹，
格式不合要求时只重试复核一次，仍严格校验字段；禁止整个付费生成阶段自动重跑。
**更正：只有重试能解决的失败才重试。** 原逻辑对端点自身的拒绝
（`ModelRefused`：鉴权、余额、内容、请求非法）也再提交一次，等待和用量都翻倍，
而这类请求重发不可能成功。现在拒绝在第一次调用后直接结束；无法解析的输出、
空回复和连接失败仍重试一次。创作草稿复核（`studio/conversation/conversation.py`）同此。
7060 与 7070 均已载入修复，76 项相关回归通过。

修复后在用户原 7060 课程的第 8 幅画上完成真实生成：页面展示完整小狗与狗屋
点评，按钮恢复为「重新评价」，原提交错误及复核解析中断均未再出现。

## 展示方式

老师评价使用画作右侧的独立阅读栏，不再放入聊天伙伴容器。显示评价标题、
正文与轻量生成／重新评价按钮，运行状态单独呈现；不展示聊天气泡、引导说明、
输入框或 Splat 步骤。窄屏时正文接在画作下方。仅修改前端，不改变生成与保存。
