# 创作内容确认流程

用户确认的流程，以本页为准。

- **让画动起来**：进入活动时，根据当前原画与该画已有完整对话自动生成动作／场景描述。老师可以直接编辑或重新生成描述；点击「确认描述，生成动画」才发起媒体生成。描述未通过复核时，提示下方列出复核指出的问题；老师把描述改成自己的文字后可以直接确认，与故事书「全部改写即老师自有」同一规则，未改动的被拒文本不能确认。
- **做本故事书**：先选 2–8 幅画、调整顺序，再根据对应场景描述生成连续情节。缺少描述时，根据原画与已有对话自动补出。情节按幕可编辑，也可整体重新生成；点击「确认情节，生成故事书」才制作书。
- 每次只显示当前步骤。停止、失败、活动间切换保留本编辑会话的文字。改变选图、顺序或场景后，旧情节不能直接确认，需要重新生成。保留孩子的独立结尾页。
- 阅读已完成的故事书不改写文字、不重新生成作品。形体与光影的流程保持原样。

## 实现契约

复用课堂请求、事件流、取消、课程归属与只读检查：

| 请求 skill | options | 输出 | 行为 |
| --- | --- | --- | --- |
| `scene-description` | `previous` 可选 | `text` | 原图安全检查后调用课堂文字模型，描述最多 600 字符，不调用媒体模型 |
| `story-outline` | `scenes`（画作 ID → 描述）、`previous` 可选 | `outline`、`scenes` | 安全检查所选原图；Qwen 直接补缺失描述并按选图顺序写情节，校验文字长度、页数与顺序，不做 Step 独立草稿审核；老师确认后再成书 |
| `painting-to-animation` | `hint` | 现有媒体输出及 `scene_description` | 使用确认后的描述，继续走现有媒体生成和安全检查 |
| `book-pictures` | `styles` | `pictures` | 绘本风格：一张画最多四种风格（第一页供老师挑选），或最多七张画一种风格；每次最多八张。先列出每张画必须保留的内容，FLUX 一次画完，逐张安全检查并与原画比对，改动了内容的重画一次，仍不一致的标出来给老师看 |
| `drawings-to-storybook` | `pages`，可选 `look`（`original` 或风格名）与 `motion`（播放短片的画） | `pages`（含 `picture_url` 或 `video_url`）、`look` | 校验页数、画作归属、顺序和非空文字，原样使用确认后的情节；绘本风格用已画好的新画，原画按老师的选择配短片 |

旧调用未提供 `pages` 时仍使用已有确认文字，以兼容历史调用方。
生成的描述／情节作为 `kind=draft` 活动保存，不混入对话朗读或已完成的故事书列表。
恢复课程时读取保存的描述、情节和顺序。尚未再次提交的手工修改只保留在当前
编辑会话；动画成功或故事书生成后，其确认文字随作品持久保存。

前端：`studio/page/src/29a-creation.js`、`07-creation.css` 与主页面接线。
后端：`studio/conversation/creation.py`、`studio/conversation/conversation.py`、`studio/classroom/classroom.py`。
提示词唯一来源：`skills/drawings-to-storybook/assets/prompts/`（从 `studio/prompts/creation/` 迁入技能目录，运行代码 `studio/conversation/creation.py` 直接读取该处）。不增加模型供应商、生产依赖或数据库表。

## 验证范围

`tests/conversation/test_creation.py` 用脚本模型验证真实课堂编排、完整对话、缺失场景补齐、
顺序校验、确认文字原样成书、取消与持久恢复；`tests/page/creation-flow.test.mjs`
验证前端确认边界、旧情节失效、取消后保留文字和跨课程隔离。
浏览器使用隔离的 mock 课堂与公开测试图验证界面；这些检查不是实际模型的生成质量验收。
# 任务状态提示

应用内浏览作品集、课程记录或切换活动时，任务继续运行。通过“返回当前任务”回到原活动、画作和故事顺序；后台完成和失败均保留，返回时展示。运行期间可以查看其他课程，开始另一堂课的编辑前需完成或主动停止当前任务。此处的状态保留不包含刷新、关闭页面或服务重启后的恢复。

创作任务显示提交中、服务器已接受、当前处理阶段和等待时长；服务器上报加载、排队或百分比时显示对应信息。未上报百分比时使用不定进度条，不按时间编造完成率。超过该任务的实测常见耗时后，才提示可继续等待或停止返回；在此之前显示该耗时，避免把正常时长读成故障。动画（视频）取 5 分钟，依据 285 秒与 297 秒两次整链实测；其余任务仍为两分钟。

提交未被接受、无法连接课堂服务器、结果连接中断、模型不可用、资源不足及保存失败分别提示。连接中断不代表后台任务失败，提示恢复连接后查看课程记录；不自动重复生成。失败与停止保留编辑内容。

当前同步动画接口未提供模型加载／采样细分进度，因此只显示已知处理阶段；这不代表已接入实际模型采样百分比。
