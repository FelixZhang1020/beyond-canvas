Everything StepFun sells, the studio buys on the subscription. Its eight StepFun jobs — the six that read and judge, the voice, and hearing — go to the plan's own address, api.stepfun.com/step_plan/v1, instead of the pay-as-you-go api.stepfun.com/v1. The plan sells no 3D and no video, so those stay on the studio's own GPU machine; the picture stays there too by your decision, although the plan includes StepFun's own image editor.

Every class sends a child's recorded voice to StepFun. Local First used to keep recordings on hardware you own, hearing with Whisper on the 4090. It was archived, with this consequence stated before you decided. Before transcription was bought at all, none of the options sent one anywhere: the code said a recording would never go to another computer and called that a selling point. That sentence has been rewritten everywhere it appeared rather than left standing.

What doesn't fit

Eight things worth knowing that the page's status panel doesn't show.

The child's drawing and voice both reach StepFun Every drawing is sent to StepFun to be read, described and safety-checked, and every recording to be transcribed. It is the honest cost of buying a good language model, and the one line in this design that a "runs on your own hardware" claim would not survive — on the Spark too, where everything the studio owns runs locally. One recording per drawing, the child's first spoken answer of at most ten seconds, is kept on the Spark for the storybook voice; no other recording is stored.
A class runs on the Spark or not at all API First needed no hardware and was the fallback for a machine without a GPU; it was archived, and then the Mac + 4090 way. A class now opens only at the Spark's address; if one of its models is down the page says which, and nothing falls back to a paid service. A collaborator cloning the repository writes and tests code on their own machine and opens the class on the Spark.
The voice is the slot with no open weights The entry's own rule is that every slot resolves to a model with open weights you can run yourself. stepaudio-2.5-tts has no downloadable weights at all. VoxCPM2, the open voice Local First ran on the 4090, went into the archive with it — so the Spark speaks with a bought voice like everywhere else. Of everything in this design, that is the gap.
The showpiece moved onto the subscription with the archive The temple showpiece, the Harness page, the photo judge and the teacher-review fallback used API First's settings, billed per use. Since the archive they use StepFun First's: the same step-3.7-flash, on the plan. A long showpiece run that meets a limit of the plan would slow down or stop rather than spend the balance. The evals, the day-zero script and the voice lab still use their own development settings.
Which account pays cannot be seen from here Both addresses take the same key and answer normally, and StepFun's responses carry no billing field at all. That a call to the plan's address is charged to the plan is therefore inferred, not measured — strongly, since the two addresses list different models, but a catalogue is not a bill. One class and a look at the plan's usage page settles it. If the inference is wrong, the cost is only that the plan goes unused.
The archive left code that nothing now calls Kept so an archived option can come back whole: the hosted 3D router cloudmesh (TRELLIS.2 on Replicate, Pixal3D on fal.ai at about $0.30 a call), the 4090 voice client for VoxCPM2 and the Whisper client for the 4090. None is used by StepFun First. cloudmesh is a router inside this codebase, not a company with an account — the status board has always translated it back to Replicate or fal.ai.
A sixth media route exists but is in neither place mesh.fast (InstantMesh) is configured in the cloud, local and spark development profiles and called by nothing. It is config, not a route — read the sketch-to-3D measurements before proposing a replacement, since the field was already surveyed.
The plan sells ten models; pay-as-you-go sells thirty-six Read live from each address. The plan's ten are a subset of the other list, and they include all three this studio uses. The twenty-six it leaves out include a whole newer generation of voice models (stepaudio-3-tts, stepaudio-3-asr-max and others). Nothing uses them now; to try one, that one job would be pointed back at the pay-as-you-go address.
