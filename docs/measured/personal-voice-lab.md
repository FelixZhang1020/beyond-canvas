# 个人语音小实验

应用户要求增加的本人声音测试工具，独立于儿童课堂。
入口：`studio/voice_lab.py`；页面：`studio/voice_lab/`。

后续：用户已选择 StepAudio 2.5「气质温婉」女声，当前源码的对话朗读
已切换到该云端预设声音，详见[接入与实测](selected-dialogue-voice.md)。
本次新版在 7270 提供；以下早期验证记录保留原时点的事实。

配置修复：课堂看图切到在线 Qwen 后，个人语音工具改读 local 配置的
独立插槽 `vlm.voice_lab`（本机 Step3、7100），不再复用 `vlm.studio`。
下文的 `vlm.studio` 描述属于当时配置；当前朗读与复刻模型见
[Qwen 本地语音接入](qwen-voice-lab.md)。此次配置修复的测试范围见
[开发看图切换记录](qwen-development-switch.md#配置联动修复)。

## 使用

在项目目录运行：

```sh
.venv/bin/python -m studio.voice_lab
```

打开 <http://127.0.0.1:7050/>。工具只监听回环地址，不对局域网开放。
需要现有本地对话服务（7100）、Whisper（7130）以及私有配置中的
`STEPFUN_API_KEY`。密钥只在后端读取，不进入页面。

1. 点击「开始和我聊」，Step 气质温婉女声读出一个问题；重听复用已生成的声音。
2. 点击录音，自然回答约 8–15 秒，再点击停止；也可以导入自己的录音。
3. 核对整段转写，回听选出的 5–10 秒连续参考片段，单独核对其文字。
4. 点击「就是这样，继续聊」，本地模型根据回答继续追问。
5. 选择一段已确认的参考录音，填入最多 500 字的短文，点击生成。
6. 对照原声与合成声音，检查相似度、字词、自然程度；按需下载 WAV。
7. 点击「结束并清除」。刷新／离开页面也会尝试结束当前会话。

## 数据及费用边界

- 本地对话使用 local 配置的 `vlm.studio`；转写通过直连 Whisper 绕过本机代理。
- 伙伴回复的文字发往 Step 云端合成预设声音；本次对话音频只缓存于会话内。
- 录音以单声道 24 kHz PCM 进入工具，转写副本重采样为 16 kHz。
- 通过音量、有效说话时间和爆音筛选连续参考片段。这不是说话人分离、身份
  检测或音色相似度评分；多人重叠仍需本人回听发现并重录。
- 参考片段重新转写，避免裁剪后的声音误配整段回答文字。
- 点击生成才将所选参考录音、参考文字和短文发往阶跃星辰。
  使用 `stepaudio-2.5-tts` 的 `audio/voices/preview`，不创建正式音色资产。
- 按官方试听建议将短文分为不超过 48 个 Unicode 字符的片段，拼接 WAV。
  段间情绪、音色一致性仍需试听。括号替换为停顿标点，保留括号中的文字，
  避免模型把这些文字当作不发音的指令。
- 费用按公开合成单价 ¥5.8／万字符估算，不是实际账单。失败的收费请求不自动重发。
- 本地服务不将录音、文字或结果写入文件；页面只保留内存和临时 Blob URL。
  结束会话会清除本地引用，闲置 30 分钟的会话也会清理。下载文件由用户自行保管。
- 每次生成的上传文件在成功、失败或取消之后都请求删除。删除未确认时页面提示，
  后台每 30 秒重试，仅针对本工具自己创建的文件。普通退出会等待在途生成收尾。
  强制杀进程、上传成功但响应丢失等情况仍可能需要到平台清理；文件删除接口的
  成功不能证明平台日志、备份等也已被删除。
- 每个会话最多 6 段录音，最多 8 个同时打开的会话；全工具同时只生成一篇短文。
- 这是用户本人测试任意文章的工具，不代表儿童课堂已接入音色克隆，也不修改儿童
  克隆只能读本人原话、须独立监护人同意等原产品规则。

## 本次验证

- 最终专项后端测试：53 项通过（包括转写、媒体接口及新工具测试）。
- 全部页面模块测试：63 项通过。
- 全部默认后端测试：593 项通过、8 项 live 未选中、1 项失败。
  失败为 `test_the_shipped_profiles_have_no_collision_left`：工作区并行增加的
  `vlm.sketch` 与 `vlm.studio` 共用同一个本地模型／端口，模型面板将其标记为冲突。
  新工具没有修改这些模型配置或面板，未为通过测试改变其判定。
- 浏览器中使用系统合成的成人测试音频，实际完成导入、双份转写和参考选择：
  参考片段约 8.94 秒，转写耗时约 0.45 秒。
- 本地模型实际接住回答并追问，耗时约 2.9 秒；没有使用备用问题。
- 实际付费试听：31 字，页面记录约 4.5 秒，返回 7.2 秒音频；浏览器播放器
  `readyState=4`、无播放错误，服务报告参考上传已删除。
- 验证了结束／过期清理、会话隔离、跨来源请求拒绝、错误响应不返回云端原文、
  生成失败及取消仍清理上传、删除失败可重试、清理线程不删除生成中的参考文件。
- 初次浏览器检查发现共享朗读模块早于语言初始化注册事件，已改为先初始化语言
  再加载模块。独立新页面已验证没有浏览器错误，只影响此工具的加载顺序。

用户开始亲自录音后保留了 7050 的在用会话，没有重启进程。核心功能是该进程中
实测的版本；最后补充的普通退出等待清理、上传结果不确定时的提示在下一次启动时
生效。最终后端源码已完成上述专项回归。

以上模型试听使用合成成人声音，只能证明接口和播放流程，不能证明用户本人或
儿童音色的相似度。麦克风与实际音色的主观验收由本人操作录音后完成。

### 用户实测后续：文章没有声音

- 用户确认录音原声可以播放，但文章没有声音。页面实际显示云端 HTTP 400，
  不是播放器静音；两段已确认的用户原声均未生成第一段文章音频。
- 相同文章首段配合系统合成参考音频可成功调用，因此不能仅凭这一对照认定
  请求协议完全正确或用户录音质量不合格。旧进程没有保存云端拒绝详情，具体
  原因仍未确定，不能把错误提示改进当作合成问题已经修复。
- 新代码区分上传与合成失败，并将已识别的参数／录音技术错误映射为固定提示；
  不返回云端原文、个人文字、密钥或文件编号。未知错误明确保留不确定性。
  专项测试 17 项通过，包含错误阶段、已知／未知参数对照及私人内容不回显。
- 7050 的在用页面与录音未刷新、重启或清除。当前内置浏览器的 Blob 音频下载
  未产生可取得的文件，无法将旧录音导入新版复现。另在 7250 打开排查页，
  等待用户提供新录音后继续确认拒绝原因；用户本人文章合成仍未验收通过。
