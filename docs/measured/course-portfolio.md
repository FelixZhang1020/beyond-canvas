## 后续：手动下课、只读与重新打开

用户要求独立的「设为已下课」按钮；下课后只能查看，要修改或添加画作必须重新打开。
课堂返回区及课程 Profile 均提供此按钮，确认后进入只读 Profile。已下课课程隐藏改名、
编辑和结尾输入；原画、对话、成果查看与朗读／导出继续可用。点击「重新打开课程」恢复
同一节课的编辑；未下课课程可直接「编辑课程」。刷新、离开、切换课程或关闭服务仅释放
编辑会话，不设置下课状态。既有已下课记录保持原状态，不自动批量重新打开。

后台按课程状态限制名称、设置、画作、确认原话、生成成果与书页结尾的写入。检查和保存
位于同一 SQLite 写事务；关闭课程返回 HTTP 409。课程 ID 保持不变，每次恢复使用新的
编辑会话 ID，失效的旧编辑接口返回 404；旧页面退出和晚到的模型结果不会写进重新打开的
课程。恢复原图、确认原话、开场上下文与页面对话，但不恢复安全判定缓存或未确认草稿。
新模型活动仍需安全筛查。没有新依赖或数据库结构迁移。

- 前端验证独立按钮、仅在保存成功后跳转、取消／失败可重试、刷新不下课、无活动编辑器时

## 当前行为

- 首页是课程列表：按创建时间倒序、每页 24 条，可按名称／课程说明搜索、按彩画／素描筛选。
- 开课可命名，也可保留自动名称；未下课 Profile 可以改名，显示日期、类型、课程说明、作品、
  确认原话、Splat 回应和已经完成的动作预览、立体成果、故事书。
- 每幅原画与其对话关联；故事书保留原画、确认原话及老师确认的结尾。没有说过的内容留白。
- 回看直接读取保存结果，复用现有查看器，不重新生成图片或立体模型。历史书页可调用常驻本地声音。
- 回首页保留当前课堂并提供继续入口；开始新课会建立独立课程，包括再次选择同一种入口的情况。
- 手动下课后回到只读 Profile。确认采用页面内弹窗；取消保留当前课堂，保存失败保留工作状态供重试。

`studio/portfolio.py` 使用标准库 SQLite，默认存储在忽略目录 `.studio/portfolio.sqlite3`。
课程设置、原画、确认原话与完成成果在成功响应前写入事务；立体模型及图片大结果仅在打开时读取。
每次操作使用独立连接，文件权限为 0600。`studio.serve --portfolio PATH` 可以选择另一个本地数据库。
下课仍释放临时图片副本、录音／语音缓存、模型会话和诊断记录；持久作品集保留。

API 与字段的规范见[页面接口契约](../specs/studio-page-contract.md)。
前端入口为 `05-portfolio.css`、`24c-portfolio.js`，沿用原生 JavaScript 和现有单文件构建。
未增加运行依赖。

## 运行入口与边界

本轮新版服务为 **http://127.0.0.1:7090/**。保留旧的 7060 进程，以免中断旧页面里的课堂。
准备好的本机环境启动命令为：

```sh
scratch/voice-candidates/vox-venv/bin/python -m studio.serve --profile local --port 7090 --speech-provider voxcpm --ledger .studio/portfolio-ledger.jsonl
```

交付前健康接口返回 `portfolio=true`、本机 VoxCPM2 可用；数据库内有上述 3 节样例课、3 幅原画。
原有 `studio.start` 启动新服务时同样使用当前 Portfolio 实现。

这是本机留存，尚无跨设备同步或儿童账户。已下课课程用于回看，手动重新打开才恢复编辑；
旧版本已经清除的课程不能恢复。立体场景回看允许临时调灯／转动，保存的是生成时的场景。
真实录音设备、成品下载实际落盘和 Spark 验收仍沿用[前次整合记录](classroom-integration.md)
的未完成边界，不以本轮历史页面测试替代那些验收。
