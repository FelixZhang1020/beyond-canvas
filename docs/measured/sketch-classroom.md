# 正式素描课堂：云端 3D 接入与本地验收

用户确认优先完善素描 3D 课堂，并明确选择先完成本地验收、不做付费生成。

## 已接入

- `cloud` / `local` 的 `mesh.portrait` 改为 `cloudmesh`。默认 TRELLIS.2，老师可在
  「形体与光影」选择 Pixal3D；一次操作只提交选中的模型，不自动付费回退。
- 先执行现有图像安全筛查，通过后直接进行单图 GLB 生成，支持头像、几何体、水果等
  输入，不再要求本地 VLM 先把整张图归类成几种几何体。仍不能保证任意输入质量。
- 复用现有 Replicate / fal 队列客户端。TRELLIS.2 固定版本
  `52e1ad6852599ea10ce8e257635a3c11485cba51c181ea5173e34d9b2955b226`，1024 cascade，
  decimation_target 100000，纹理 1024，seed 42；Pixal3D 使用 fal-ai/pixal3d，
  1024、纹理 1024、decimation_target 100000、seed 42。不同服务的目标数值语义
  不保证等价，实际显示面数另外检查。
- TRELLIS.2 读取 REPLICATE_API_KEY；Pixal 优先 FALAI_API_KEY，其次 FAL_KEY。
  密钥仅在服务器使用，未写入页面或课程结果。
- 模型下载只接受指定供应商 CDN，检查每次重定向；限制 16 MiB、35 万三角面及
  元数据分配预算，拒绝外部资源、压缩网格和实例膨胀。只检查容器和 JSON 元数据，
  没有在服务器解码网格、贴图或进行减面。浏览器加载时覆盖原材质，跳过原始贴图。
- GLB、哈希、大小、实际面数和模型标识随课程成果存入现有 SQLite；历史成果不依赖
  供应商临时下载 URL。课程列表不读取大成果，打开某份成果时才读取。
- 同一会话、同一幅画按选定模型缓存成功结果。切换备选后再切回成功的首选可复用；
  新会话重新点生成仍是新的生成操作，打开历史成果不生成。
- 正式查看器 `/viewer/3d/classroom.html` 与展示项目共享渲染器，使用单模型课堂布局：
  原画对照、拖动旋转、自动旋转、五种材质、灰度、可调方向光、地面投影、PNG 导出。
  玻璃观察隐藏不透明地面，以便看见背板条纹折射；其他材质恢复勾选的地面状态。
- 关闭查看器移除 iframe；页面卸载时释放渲染目标、材质和上下文。单模型按需绘制，
  不在调光或换材质时调用生成 API。
- 本地整合启动器不再为云端 3D 启动 Step3-VL 或 TripoSG；转写可独立启动。
  Spark profile 仍保留原实验配置，本轮没有在 Spark 上部署或切换它。

## 入口

正式服务：`.venv/bin/python -m studio.serve --profile local --port 7000`（先确认端口空闲）。
它使用既有 `.studio/portfolio.sqlite3`，不加载本地语音权重。完整语音启动方式仍见
`studio/page/README.md`。后端代码更新需要重启对应服务。

本轮验收服务为 http://127.0.0.1:7140/ ，使用隔离的 `.studio/sketch-acceptance.sqlite3`，
三门课程明确命名为「验收样例（已有模型）」，来自前期真实生成档案；不是本轮新生成。
没有替换原课程数据库，也未停止其他课堂服务。

## 证据

- Python 全套非 live 回归通过（当次 802 项，含共享工作区其他功能测试）；最终云端
  模拟、查看器路由与访问边界聚焦回归通过。前端 128 项测试、构建和 JS 语法检查通过。
- 十份已归档真实 GLB 通过新生产边界；原十份 GLB 与八个拒绝控制检查通过。
- 模拟接口验证主备分别只提交一次、不自动回退、下载重定向／超限拒绝；课堂级模拟
  验证安全拒绝不会调用生成、成功模型按选择缓存；课程结果经过 SQLite 重开保持一致。
- 浏览器实际打开保存的几何体与头像，验证材质、光源方向、原画弹窗、关闭／重开。
  导出操作触发成功下载提示；没有检查下载文件的最终保存位置。
- 关闭后正式查看器 iframe 不再存在；这不是浏览器总内存、峰值显存或长期压测。

## 尚未验收

用户选择不付费，本次没有调用真实生成或图像筛查服务。因此代码接入、模拟回归和
历史真实模型的浏览器渲染，不等于新上传到新生成再保存的云端端到端验收。
真实生成延迟、费用、超时后的远端状态和模型质量还需后续实测。
停止等待不会保证供应商任务停止；不自动重试或切换备选，防止无提示叠加调用。

模型初始朝向为供应商约定的近似，尚未自动拟合原画构图；可以旋转观察。
玻璃厚度统一近似，无焦散／准确透光阴影；巧克力无次表面散射。
保存的是生成网格，材质和摆灯为实时观察，重新打开回到默认视图；PNG 导出记录当时画面。
未执行本地推理、真实外部生成、Spark 测试、提交、推送或公开部署。

接口依据：[Pixal3D API](https://fal.ai/models/fal-ai/pixal3d/api)、
[TRELLIS.2 schema](https://replicate.com/fishwowater/trellis2/api/schema)，以及前期归档的
固定版本 schema 与成功输入记录。页面文档的枚举展示与 schema 类型存在差别，
Pixal 分辨率按其 schema 和已成功实测使用整数。
