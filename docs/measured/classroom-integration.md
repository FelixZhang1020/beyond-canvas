# 课堂功能整合与样例库联调

本次按用户要求，把已建设的网页、图片分析、语音、素描转换接到同一个课堂入口；
后续按用户纠正，去掉程序画出的房子／太阳示例，改用现有 `Image Sample/` 样例库。
这是 Mac 开发环境的实现与实测记录，不是 Spark 或真实儿童课堂验收。

## 当前入口与实现

准备好现有模型环境后，运行 `.venv/bin/python -m studio.start`，打开
<http://127.0.0.1:7060/>。`--check` 只检查本机服务、安装路径和私有配置是否存在。
启动方式、运行库位置及准备要求以 [页面维护说明](../../studio/page/README.md#integrated-classroom)
为准。启动器复用已响应的本地服务，不结束其他实验页面，不自动安装依赖或下载模型。

- 样例库：彩画课堂 69 张、素描课堂 8 张；按入口显示缩略图，选择后进入原有导入、
  安全检查和技能流程。图片留在忽略目录中，不打包进网页；响应去掉元数据并限制尺寸。
  不存在的样例、越界路径和其他入口的图片不可访问。结束该课堂后，其样例访问地址失效。
- 图片分析与对话：沿用 Qwen3-VL + 独立 StepFun 安全／质量检查。设置里的课堂目的与
  语言同步到已创建的后端对话。质量拒绝保持拒绝，没有绕过规则以取得成功输出。
- 语音：课堂进程常驻预热 VoxCPM2，使用既有成年合成男女声，复用语音实验的流式播放器。
  反馈、问题、回应和书页走同一个通道，支持重听、音色切换、停止和会话缓存清理。
  没有接入儿童录音参考或音色克隆。默认真实网页连接失败时不再悄悄切换模拟回应。
- 听孩子说：网页转换为 16 kHz 单声道 WAV，送本地 Whisper，结果先进入老师确认栏。
  修复了环境 HTTP 代理错误接管 localhost 转写请求的问题。切图、结束课堂或重新录音后，
  旧的权限／音频回调不能覆盖新课堂。
- 素描：沿用现有几何／混合静物和 TripoSG 路由，结果接回主页面的旋转、摆灯和投影查看器。
- 动作预览：现有 Klein 路由接收该作品确认过的原话作为动作提示，展示原画和生成的静态画面。
- 故事书：后端开放 2–8 张原画与老师确认过的原话的静态装订，每张画分别筛查；
  没有原话时保留图片页，最后一页由孩子／老师填写。不会额外生成故事或代编结尾。
  下一位小画家不再清掉前面作品的回答。书页可用本地声音朗读，HTML 成品嵌入图片和文字，
  不包含朗读音轨。空白图页不显示无内容可读的按钮。
- 取消：网页停止会通知后端，停止后续阶段及迟到的结果。已经运行的同步云端／GPU 调用
  可能继续到返回，期间该课堂的新活动会收到忙碌提示。结束课堂清理上传图、语音缓存和记录，
  尚未返回的工作在结束时再清理迟到记录。

多页书接入时发现同一请求内的阶段完成缓存只按阶段名区分，导致第二张画可能复用
第一张的筛查阶段。已按绘画标识分开阶段；用第二张被拒绝的对照证明修复能阻断整本书。

## 实际服务与浏览器验证

真实服务为本机课堂 7060、Step3 素描识别 7100、Whisper 7130、TripoSG 7240，
另调用既有配置的 OpenRouter、StepFun、Replicate。开发环境并非完全离线。
没有访问真实儿童麦克风；音频导入使用公开测试文字生成的成人合成录音。

| 流程 | 证据 |
|---|---|
| 样例选图 | 浏览器打开彩画 69 张缩略图与素描 8 张缩略图；选取库中的小狗作品及 `Fruits 2.png`，没有替代示意图 |
| 彩画对话 | 库中作品 12：真实反馈描述小狗、屋子与星星；导入合成录音成功进入确认栏；改为测试原话「小狗想在星星下面跑步。」后得到接住原话的真实回应 |
| 动作预览 | 同一小狗作品完成真实 Klein 调用，查看器呈现原画与静态新动作画面 |
| 语音 | HTTP 男女声均返回完整 PCM 和完成事件，重听命中缓存；浏览器反馈、回应、男声切换和书页朗读完成。未作扬声器音质验收 |
| 素描立体 | 库中苹果／梨完成真实重建；浏览器看到可交互立体表面，改变灯的左右位置后，明暗和投影方向变化，视角键盘操作可用 |
| 故事书 | 浏览器选作品 12 与 14，真实后端返回两页；第 1 页保留前面确认的原话，第 2 页无原话而留白；最后一页可填写确认结尾，第一页可朗读 |
| 会话结束 | 实际 HTTP 测试结束后，原作品地址返回 404；异步取消、迟到回调、缓存隔离和结束后清理另由针对测试验证 |
| 导出 | 自包含 HTML、文本转义、图片嵌入及 PNG 渲染路径有现有自动化覆盖。内置浏览器点击 PNG／HTML 导出无脚本错误，但未返回下载事件，未确认文件落盘；不能把提示消息当作下载验收。提示已改为「已发起下载」 |

一次已预热环境的实际 HTTP 计时如下。首块时间是 HTTP 收到 PCM，**不是扬声器起播**；
不包含文字模型思考，不代表每次请求的稳定上限。

| 项目 | 时间 |
|---|---:|
| 苹果／梨首次重建 | 124.261 秒 |
| 同一绘画重建缓存 | 0.134 秒 |
| 素描开场反馈（两次） | 22.565／38.753 秒 |
| 女声首块／完整生成 | 0.283／2.584 秒 |
| 男声首块／完整生成 | 0.169／2.399 秒 |
| 女声完整缓存重听响应 | 0.002 秒 |
| 短合成录音转写（两次） | 1.124／0.162 秒 |

转写将「梨子」识别成「离子」，说明老师确认仍必要。最初整链脚本因此在严格文字断言处停止；
修订为检查相似度并由老师纠正后，另一轮素描回应被质量规则拒绝，未放宽规则。
这两次脚本都执行了会话清理，不能称作两次全流程通过；彩画回应、装订与浏览器流程的
成功证据分别如上。原始计时摘要保存在忽略目录 `.studio/integration/`，不提交私有作品或录音。

## 自动化与边界

- 全仓 Python：726 项通过，8 项在线测试按默认配置未运行；不是 726 次真实模型调用。
- 全部页面模块：111 项通过；单文件页面构建和结构检查通过。
- 最后针对整合、样例和转写的 22 项通过，包括故障代理的反例与正常直连，
  多页安全拒绝、语音截断／取消／音色缓存隔离、跨会话访问和设置同步。
- 实际模型调用及浏览器检查与上述自动化分开记录，不混作服务、设备或教学效果证明。

未验收项：真实相机／麦克风权限与课堂噪声、扬声器音质、内置浏览器下载落盘、
Spark 与跨设备访问、进程崩溃后的自动清理／课堂恢复。连续动画、深度场景、
儿童音色克隆仍不属于当前已实现的课堂能力。
