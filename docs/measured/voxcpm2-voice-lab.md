# VoxCPM2 本地对话与参考音色朗读

用户听过候选后选定 VoxCPM2，同意采用模型常驻、启动预热、固定声线缓存
和对话边生成边播放。本次已落实到独立的成人语音小工具，入口为
`http://127.0.0.1:7320/`。此前页面和录音会话保留；没有改动儿童课堂的语音路径。

## 当前行为

- `studio/voice_lab.py` 默认选择 VoxCPM2，默认端口 7320。设置提供此前试听的
  温柔女声／温和男声，来自本机设计的成年合成参考，不是真人或 Step 专有音色。
- 一个模型常驻单一工作线程。启动时加载两个固定声线的参考特征，预热流式解码及
  文章参考编码，完成后才开放页面；对话与文章任务串行使用模型。
- 对话通过 `/api/speech-stream` 逐块返回 PCM。浏览器缓冲约 0.32 秒音频后开始播放，
  后续音频连续排队。完整问题按会话、问题和声音缓存，重听无需再次生成。
- 录音、切换声音、停下或结束会话会取消旧播放，迟到的数据不能重新出声。
  中断或失败的片段不进入完整音频缓存；浏览器不允许自动播放时保留手动播放器。
- 文章使用选中录音及核对后的文字作参考，仍在整篇生成完成后播放。
  个人参考通过内存流交给模型，生成结束、失败或取消时清除参考特征和推理缓存，
  不创建长期音色档案。原声样本与文章音频保留在本次会话内，结束时清除。
- Whisper 转写及 `vlm.voice_lab` 的本机 Step3-VL-10B 文字对话沿用原配置。
  VoxCPM2 负责发声和参考音色朗读，不承担文字问答。

## 本机实测

Apple M5 Pro / 64 GB，官方 PyTorch MPS / float32。沿用
[候选试听记录](voxcpm2-cosyvoice3-audition.md)中的固定源码、权重和隔离环境，
没有修改供应方模型实现。本次启动加载 13.4 秒、预热 11.9 秒，这发生在服务开放前。

HTTP 测试开场为工具默认问题，追问为本机文字模型接续公共合成录音生成的问题：

| 场景 | 首个 PCM 到达 | 完整合成 | 输出音频长度 |
|---|---:|---:|---:|
| 女声开场 | 1.65 秒 | 7.84 秒 | 7.20 秒 |
| 男声开场 | 0.20 秒 | 4.68 秒 | 5.28 秒 |
| 女声新追问 | 0.45 秒 | 6.51 秒 | 7.04 秒 |
| 男声新追问 | 0.22 秒 | 6.00 秒 | 6.56 秒 |
| 已缓存女声开场 | 约 0.001 秒 | 约 0.003 秒 | 7.20 秒 |

浏览器另开真实会话：女声开场约 **2.51 秒**、男声开场约 **2.07 秒**开始调度播放。
此指标由页面记录，包含请求和起播缓冲，不包含扬声器硬件延迟；不能把 HTTP 首块
0.20 秒当作用户实际听到声音的等待。测试为单次样本，不是平均值或并发性能保证。
生成速度接近播放速度，重任务争用时仍可能出现停顿，尚未做长时间压力测试。

公共合成录音的整段及参考片段转写共 0.39 秒，文字追问另用 4.24 秒。
完整对话等待还包括这部分文字生成，不能只引用声音合成计时。
测试短文“午后的阳光落在窗边，桌上的茶还冒着一点热气。”生成约 6.5 秒，
输出 5.92 秒音频，本机 Whisper 核对覆盖全文。没有使用用户或儿童录音，
本人音色相似度仍需实际回听；本次未验证 Spark、课堂并发或完整 145 字默认文章的耗时。

## 验证与产物

- 45 项 Python 语音专项检查、15 项页面播放检查通过。覆盖串行推理、缓存隔离、
  流中断、取消、参考清理、会话／来源校验、自动播放回退及原生播放器重听。
  这些测试使用模型替身，真实推理证据是下列独立 HTTP 和页面检查。
- 真实本机 HTTP 流程完成会话、录音导入、两次转写、确认、追问、两种声音、
  缓存重听、参考音色文章和结束后音频不可访问。
- 浏览器完成男女声流式开场、设置切换、原生播放器缓存重听、生成中停下和结束。
  没有代替用户开启麦克风录制；录音输入通过公共合成音频验证后端流程。
- 实测 JSON 与公共合成音频位于忽略目录
  `outputs/voice-audition/vox-integrated/`；HTTP 复现脚本为
  `scratch/voice-candidates/check_vox_http.py`。用户原声不写入这些目录。
- 推理设置离线加载，不自动回退云端；此次 HTTP 流程使用本机 loopback 服务。
  这不同于候选试听中拦截所有 socket 的独立模型测试，不能合并为一次网络隔离验证。

## 启动与维护

从仓库根目录运行：

```sh
scratch/voice-candidates/vox-venv/bin/python -m studio.voice_lab --port 7320
```

环境需已准备候选记录中的源码、权重以及 HTTP 工具依赖。模型目录可由
`--voxcpm-path` 指定，源码由 `--voxcpm-source` 指定；默认使用现有 scratch 目录。
`--voxcpm-device mps` 为本机已验证路径，CUDA／CPU 选项未在本次集成中实测。
旧 Qwen 与 Step 路径保留，分别显式使用 `--speech-provider qwen`／`step-cloud`。
未修改生产依赖清单，未部署到其他机器。

实现入口为 `studio/providers/voxcpm_voice.py`、`studio/voice_lab.py` 和
`studio/voice_lab/stream-voice.mjs`。两个公开合成参考存放在
`studio/voice_lab/voices/`，来源见该目录说明。
