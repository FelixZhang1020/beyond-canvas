# 从《点评集合》提炼的反馈方法

来源：老师的点评文档《点评集合》（不随项目发布）。
按正文顺序对照文字及 23 张独立内嵌图片；其中《会走路的房子》第三集图片
在原文重复出现，预告文字与点评分开读取。未修改原文、复制学生称呼或把
原图加入公开测试素材。下表序号是内嵌图片顺序，不是 Word 页码。

## 图文观察与采用方式

| 图片 | 原文讨论的画面 | 可迁移的方法 |
|---|---|---|
| 1、8 | 白桦林与室内；窗外城市与门外沙漠 | 说明不同空间如何在同一画面并置，不把超现实空间当透视错误 |
| 2、9 | 风铃花角色；人物与花枝线描 | 将同类色、人物造型与互动联系起来；少色作品关注点线面和疏密 |
| 3 | 番茄角色群像 | 从渐变、遮挡、表情和动作解释体积与角色关系 |
| 4 | 弧形建筑与鲨鱼 | 从连续弧线解释包围视野的效果，不只贴“鱼眼透视”标签 |
| 5、6 | 对照世界；分割画面与角色 | 从曲线、分割、色彩对照解释视觉张力；真实经历与象征意义须由孩子确认 |
| 7 | 奔跑人物、油漆与场景线索 | 观察动作及细节怎样引出叙事，再问孩子发生了什么 |
| 10、11、12 | 会走路的房子；小猫与湖面倒影 | 结合已提供的故事解释构图；没有故事输入时不能套用原文剧情 |
| 13 | 理发店 | 尊重混合视点，指出分区如何让多个活动同时可见 |
| 14 | 海底综合材料作品 | 将可见凹凸、彩色波浪线与画面节奏联系；材料名称不能仅凭照片确定 |
| 15 | 花园与喷泉 | 从视觉中心、前中后景、色块和笔触解释空间与动感 |
| 16 | 装备人物与战争场景 | 关注可见的装备细节和背景组织，不推断作者心理或兴趣经历 |
| 17 | 钞票主题线描 | 观察字体、建筑、点线面与黑白层次，不将参照物或画外文字误当作品细节 |
| 18 | 游轮与海面 | 解释主体体积、周边小场景与夕阳倒影各自的作用 |
| 19 | 溪流线描 | 解释曲折构图如何引导视线，以及线条怎样区分石块和流水 |
| 20—23 | 四张人物素描 | 分别检查造型结构、明暗组、虚实和完成程度；强烈明暗不等于结构准确 |

## 运行中的反馈原则

开场保持两到四句加一个问题：**可见细节 → 一项画面处理及其效果 → 与该细节相关的问题**。
不逐项打分、不堆术语，不把原文的长篇教师总结直接塞进儿童对话。

彩画从色彩关系、空间组织、线条节奏、肌理、动作互动中选择最有证据的
一至两项，用孩子听得懂的话说明效果，最后邀请孩子讲画里的事。
回应接住孩子自己的话，再连接一个可见处理；不替孩子确认画面之外的故事。

素描先看整体、再选重点。确有可见问题时只给一个建议，包含位置、动作和
观察目标。例如仅在投影边缘确实一致时，引导比较接触处与远处的边缘。
没有明确问题就不强凑缺点；没有参照图就不声称精确的肖像相似度偏差。

## 与来源的差异和证据边界

- 原文包含彩画“小提升”，当前产品彩画入口明确不纠错，因此只吸收观察与
  表达方法。技术建议用于素描入口。入口规则见[核心设计](../../../docs/specs/art-studio-skill-pack-design.md#两个入口素描-和彩画)。
- 原文老师掌握课堂背景，因此能谈孩子的自述、系列故事和学习过程。
  单张上传图片不提供这些依据；不据此声称“比上次进步”“很有耐心”，也不
  把角色当作作者或其家人。
- 四张素描的考试分数是来源作者的估计，文档没有可复核的完整评分过程及
  写生参照。尤其末张仍有可见明暗，不能把“光影几乎缺失”当作所有同类画的
  视觉事实。采用分析维度，不采用分数、等级、录取预测或逐图质量标签。
- 摄影背景、手持作品的人、装裱底色和纸张倾斜都不应成为对画作的评价依据。

实际提示词位于 [prompts](../assets/prompts)，由
[feedback.py](../scripts/feedback.py) 在开场和回应时读取，中英文共用。
本次验证为本地提示词、对话与判卷回归；未提交真实模型请求，不能据此宣称
模型对这 23 张画的点评质量已实测提升。后续视觉验收应同时检查细节真实性、
处理与效果的因果联系、问题是否承接观察，以及是否擅自沿用原文背景。

同日后续经用户明确要求，已用官方 StepFun 3.7 Flash 完成样例库 74 个彩色
图片文件的真实点评与复核，见[实测记录](../../../docs/measured/colour-feedback-stepfun.md)。
该批次不是文档 23 张内嵌图的逐一复测，也没有旧提示词对照；发现的点评和
判卷问题均保留，不能把自动通过率当作改进幅度或教师验收。
