# 素描三维方案选择

用户确认：**TRELLIS.2 为项目首选，Pixal3D 为备选**，随后在真实
运行环境继续测试。此为方案选择，不代表现有课堂 provider 已接入或自动回退已实现。

选择依据是[三图四模型实测](measured/four-model-comparison.md)中的
样本形体、底板、碎片及统一光照表现，不是全部输入的模型排名。

后续真实环境验收需覆盖：素描上传到可交互场景的完整流程、失败提示和备用方案、
端到端延迟、内存峰值、头像和多物体形体质量、初始方向与接地、移动光源后的遮挡
和投影。DGX Spark 性能尚未实测，云端计时不能代替实机结果。

## 材质测试预览

现有比较页 `http://127.0.0.1:7135/` 的“显示”菜单增加五种实时预设：

| 材质 | 表现 | 主要设定 |
|---|---|---|
| 石膏 | 暖白、微小颜色颗粒、漫反射 | 粗糙度 0.97，非金属 |
| 木头 | 暖棕、细纤维与柔和色差，纹理可关闭 | 粗糙度 0.43，非金属，无 UV 依赖 |
| 金属 | 银色半抛光、均匀环境补光 | 金属度 1，粗糙度 0.38 |
| 玻璃 | 透射、近似折射、浅色条纹背景 | 透射 1，折射率 1.5，厚度统一近似 0.65 |
| 巧克力 | 深棕、柔和高光 | 粗糙度 0.34，清漆 0.18 |

材质复用已生成的小型 GLB，不重新调用生成服务，不修改原始下载文件。
木纹与石膏颗粒是程序颜色纹理；不是 AI 生成的贴图文件，也没有烘焙导出。
木纹采用原始模型坐标，未校准不同模型的真实物理纹理尺度。
玻璃不投射普通不透明阴影，尚未实现透光阴影、焦散或真实厚度重建；巧克力
未实现次表面散射。因此该页用于视觉对比，不作为物理光学真值。

渲染采用仓库已归档的 Three.js r180 物理材质与共享 128 分辨率环境反射；
透射缓冲使用半分辨率。四份场景和相机身份复用，避免换图后不断创建透射缓冲。
默认哑光不需要生成该环境；使用过材质后保留一份环境、最多四份透射缓冲和四份独立视窗渲染目标供复用。
参数语义参考 [Three.js 物理材质](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)
和已归档源码，不代表离线路径追踪。

## 初版验证记录（后续修订见下）

五种预设均在实际浏览器以 TRELLIS.2 头像查看，木纹能辨认、金属／巧克力高光
不同、玻璃透射可见背景，石膏呈漫反射。玻璃四模型几何体显示正常；换到水果再
返回几何体后，贴图计数保持 5，几何数量恢复 52（含 48 个背景条纹平面），没有
在该次切换中累积。材质切换及金属调整方向光未出现浏览器着色器错误。

原有十份 GLB 的文件与拒绝控制检查仍通过。未进行生产接入、Spark 实测、长时间
性能压测或五种材料与实拍实物的定量比较；本轮无新增云端费用。

## 材质修订

针对用户反馈，金属改用更明亮的环境反射，保留局部暗反射；木头默认关闭木纹，
提供细木纹强度控制；玻璃去掉重复条纹背景，改为柔和双色参照。
每个视窗独立渲染后合成，隔离透射渲染过程；画布坐标按实际 CSS 宽度计算，
修正滚动条导致的窗口宽度与画布宽度差异。新增标准球体与灰度观察；球体明确标注
为测试形状，不替代缺失的模型生成结果。下载仍为原始模型，不含这些实时材质。

实际浏览器检查了金属头像、木纹关闭和最大强度、灰度、玻璃标准球体、四窗几何体、
单窗返回及滚动边界。玻璃几何体→水果→几何体切换后贴图计数保持 9，浏览器没有
着色器错误或警告。JavaScript 语法检查、十份 GLB 与八个拒绝控制检查通过。
这属于有限交互检查，不是长时间内存压测。玻璃仍是统一厚度的实时近似；本轮无
新增云端调用，也未进行 Spark 或课堂集成验证。

材质观察参考：[金属反光素描](https://www.creativebloq.com/how-to/draw-metallic-reflections)、
[木头纹理素描](https://design.tutsplus.com/tutorials/how-to-draw-textures-wood--cms-27581)、
[玻璃素描](https://design.tutsplus.com/tutorials/how-to-draw-glass--cms-27740)。
这些示例用于理解明暗、表面细节和背景折射，未复制其图像作为贴图。

### 后续反馈调整

用户反馈纯色木头缺乏辨识度、玻璃需要浅条纹参照后，木材调整为暖棕底色、
非均匀细年轮与纤维色差，默认强度 60%，仍可降至 0；不添加粗糙凹凸贴图。
玻璃背板改为 16 条浅灰蓝／米白交替条纹，保留独立视窗合成。
浏览器实看木材头像、玻璃标准球体四窗，条纹与玻璃轮廓可辨，未发现界面溢出或
着色器警告。语法与十份 GLB／八个拒绝控制检查通过。本次未做资源循环压测。

### 金属调光修订

固定灯箱和深色反射板会在金属上形成不随方向光移动的亮带／黑斑，干扰调光观察。
金属现使用单独缓存的 16 分辨率均匀环境，环境强度 0.85；方向性高光来自用户可调
方向光。其他材质保留原环境。几何体场景方向光从 -45° 调至 70° 的浏览器检查中，
球体高光与地面投影改变方向，固定黑斑消失，无着色器警告。此为简化照明观察，
不模拟真实房间的复杂反射。新增一份小环境贴图，未做长期资源压测。
