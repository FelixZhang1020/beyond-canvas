# 素描 → 3D 对比展示

独立保存的展示项目。系统课程作品集首页的「3D 对比展示」入口对应
`/showcase/3d/`，在新标签页打开，不改变课堂。展示不调用生成服务，不加载模型权重。

## 独立启动

已有系统服务时，直接从课程作品集打开 `/showcase/3d/`，无需另起独立服务。

先检查 `lsof -nP -iTCP:7080 -sTCP:LISTEN`，确认没有监听者后，
从仓库根目录运行：`python3 -m studio.showcase_3d.serve --port 7080`。
启动成功后打开 http://127.0.0.1:7080/showcase/3d/ 。也可复制整个目录后运行
`python3 serve.py --port 7080`，无需仓库其他目录或 API 密钥。
这里是启动示例，不表示该地址已有服务。若被占用，按[项目端口规范](../server/ports.py)
选择另一个空闲端口，并同步修改访问地址；临时预览同样必须遵守规范。
独立服务默认使用 7080；示例显式写出 `--port`，便于确认实际监听地址。
不要双击 HTML；模块和模型需要 HTTP 服务。

## 保存内容

- `inputs/`：三张原始素描；`assets/`：十二份可交互 GLB。
- `originals/`：十二份原始生成文件，下载采用流式读取，不在浏览器自动加载。
- `manifest.json`：样本、耗时、大小、哈希、处理方式、已知问题与真实完成状态。
- `lineage.json`：原始下载映射，全部为目录内相对路径，服务器不公开该文件。
- `archive-files.json`：27 份原图／显示模型／原始模型文件的 SHA256 和大小清单。
- `vendor/`：已归档的 Three.js r180 与许可证；无需 CDN。
- `records/`：截至保存日的评测与材质决策快照，保留历史证据与当时路径；
  其中旧地址和旧启动命令不应照抄，见[快照阅读说明](records/README.md)。持续更新的记录仍在仓库 `docs/`。

原图、显示和原始模型存在少量内容重复，完整文件夹约 504 MB（`du -sk`）。二进制资产仅保存
在本机，并被 Git 忽略；仅复制 Git 源码不能复原本次结果。备份时须复制整个目录。
本次没有上传云端、提交或公开发布。

## 功能和边界

三图切换，四模型并排／同步视角，旋转缩放和单窗放大；11 种显示选项，包含
石膏、大理石、扫描橡木、牛仔布、锈铁、金属和玻璃。同步课堂
光影能力：各窗可拖动光点、方向与高度滑杆、默认地面投影、玻璃浅投影、
带光照的表面朝向颜色。标准球体、灰度观察与木纹强度保留。材质和光源
共用查看器实现，课堂消息接收与样例清单加载仍独立。下载不包含实时材质修改。

12 份原始生成齐全，全部可交互。TripoSG 头像约 106 MB、水果约 243 MB，超出云端
减面的大小限制；在 DGX Spark 上用 Blender 减到约 10 万面（头像 24 秒、
水果 61 秒），仍是 TripoSG 自己的结果，未用替代模型填补。TripoSG 水果没有做出
苹果和梨：原图未去背景，整张画纸成了一个封闭方块，减面前的原始文件也是如此。
课堂现用 TRELLIS.2（DGX Spark）；Pixal3D 已归档。生成耗时来自不同
云端硬件，不能直接比较同硬件速度。玻璃为统一厚度近似，无焦散或准确透光阴影。

## 检查

`node test-assets.mjs` 检查十二份显示文件和八种拒绝控制，不解码纹理或大型网格。
系统集成检查：`python -m pytest tests/server/test_showcase.py tests/server/test_serve.py`（仓库根目录）。
应用资源按白名单提供，原始文件仅可经下载映射访问；私有索引、路径越界和符号
链接越界会被拒绝。页面静止时按需渲染，保留单文件 16 MiB／35 万面保护。
